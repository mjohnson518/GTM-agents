# Examples

Everything here is fictional, and safe to copy as a starting point.

| Folder | What it shows |
|---|---|
| [`brains/`](brains/) | Complete example brains. `brains/acme` is a fictional developer-tools company, written to the brain schema, with cold intro, follow-up and breakup templates. |
| [`host-nextjs/`](host-nextjs/) | A host application, meaning the product being sold, implementing the event contract in Next.js: the event emitter, the attribution cookie, the signed read endpoints and a stub proof-of-value route. |
| [`packs/`](packs/) | Domain packs for a vertical: extra discovery sources, a domain wiki or a vertical-specific adapter, each registered through the same ports as the core ones. |
| [`overlay/`](overlay/) | How a real deployment keeps its private brain, config and secrets outside this repository while still tracking upstream. |
