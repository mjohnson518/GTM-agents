# Competitors

All names below are fictional.

## globex-test-insights
- name: Globex Test Insights
- positioning: A broad CI analytics dashboard covering build times, costs and test results.
- differentiators: Acme acts on flaky tests by quarantining them, while dashboards report the problem and leave the fixing to people.
- when_we_lose: The buyer wants one dashboard for every CI metric and flakes are a minor concern.

## initech-ci-analytics
- name: Initech CI Analytics
- positioning: An add-on to a single CI vendor that flags slow and failing tests.
- differentiators: Acme works across CI providers and test frameworks, which matters for teams with more than one pipeline.

## in-house-script
- name: An in-house script
- positioning: A script or spreadsheet a platform engineer maintains on the side.
- differentiators: Acme replaces the maintenance and adds quarantine and ownership, which scripts rarely reach.
- when_we_lose: The script works well enough and the maintainer enjoys running it.
