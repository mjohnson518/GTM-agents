# Market profile

Acme is a fictional company. Every item below is invented for the example.

## category
- kind: category
- text: CI reliability tooling: products that make test results trustworthy so a red build means a real problem.

## segment-growth
- kind: segment
- text: Software companies with 30 to 300 engineers that run CI on every pull request and feel flaky tests as daily friction.

## trend-monorepos
- kind: trend
- text: Teams consolidating into monorepos run far more tests per change, so a small flake rate turns into many reruns a day.

## buying-pattern
- kind: buyer_behavior
- text: A senior engineer usually finds the tool and runs a trial; an engineering leader signs once the trial shows hours saved.

## timing-planning
- kind: timing
- text: Interest peaks during quarterly planning, when teams look for engineering-hours to win back.
