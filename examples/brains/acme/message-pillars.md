# Message pillars

## trust-red-builds
- text: A red build means a real problem again, because flaky tests are quarantined instead of retried.
- proof: quarantine-automatic
- personas: platform-champion, engineering-manager

## hours-back
- text: Teams win back the engineer-hours they spend rerunning builds and chasing failures that are not theirs.
- proof: rerun-report
- personas: economic-buyer, engineering-manager

## no-new-workflow
- text: It works with the CI and test reports the team already has, so nobody learns a new tool.
- proof: setup-time, read-only-access
- personas: platform-champion, security-reviewer

## flakes-get-fixed
- text: Quarantined tests come with an owner and a history, so they get fixed instead of forgotten.
- proof: owner-assignment
- personas: quality-lead
